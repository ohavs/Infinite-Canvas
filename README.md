# קנבס אינסופי 🎨

לוח ציור אינסופי בעברית מלאה, מיושר מימין לשמאל — עם חוויית העריכה המלאה של tldraw.

האפליקציה בנויה סביב **ה-SDK הרשמי של tldraw** (אותו מנוע שמריץ את tldraw.com), ולכן כל כלי, כל תפריט וכל קיצור מקלדת עובדים בדיוק כמו במקור — כולל התרגום העברי הרשמי והיפוך אוטומטי מלא של הממשק ל-RTL.

## מה יש בפנים

### חוויית עריכה מלאה (tldraw SDK)
- **כל הכלים**: בחירה, יד, ציור חופשי, מחק, חץ, טקסט, פתקית, מסגרת (Frame), כל הצורות הגאומטריות, קו, לייזר, הוספת מדיה והטמעות (YouTube, Figma ועוד)
- **פאנל סגנון מלא**: צבעים, מילוי, סוג קו, גודל, גופן, יישור
- **עמודים מרובים** בכל פרויקט, ביטול/חזרה, יישור והפצה של צורות, קיבוץ, נעילה, סידור בשכבות
- **ייצוא תמונה** (PNG / SVG), העתקה־הדבקה, וכל קיצורי המקלדת המוכרים
- **מצב כהה / בהיר** — כברירת מחדל לפי מערכת ההפעלה, ניתן לשינוי בתפריט
- **עברית מובנית**: התרגום העברי הרשמי של tldraw + פריסת RTL אוטומטית של כל הממשק

### ניהול פרויקטים (מסך הבית)
- יצירת פרויקטים ללא הגבלה, כל פרויקט עם קנבס עצמאי
- תמונה ממוזערת חיה של כל קנבס, "עודכן לפני..." בעברית
- שינוי שם, שכפול (כולל כל תוכן הקנבס) ומחיקה
- ייבוא וייצוא קבצי `‎.tldr` — תואם במלואו לקבצים של tldraw.com

### אחסון — Local-first
כמו ב-tldraw.com במצב אנונימי, הכל נשמר **בדפדפן שלך, אוטומטית, בלי חשבון ובלי שרת**:

| מה | איפה |
|---|---|
| תוכן הקנבס (צורות, עמודים, מדיה) | IndexedDB — מסד נפרד לכל פרויקט |
| רשימת הפרויקטים, שמות ותמונות ממוזערות | localStorage |
| העדפות משתמש (שפה, ערכת נושא) | localStorage (מנוהל ע"י tldraw) |

שום מידע לא עוזב את המחשב. רוצים גיבוי או העברה בין מחשבים? תפריט ראשי ← „שמירה לקובץ ‎(.tldr)" ואז „פתיחת קובץ" במחשב השני.

## הרצה

```bash
npm install
npm run dev        # פיתוח — http://localhost:5173
npm run build      # בניית פרודקשן לתיקיית dist
npm run preview    # תצוגה מקדימה של הבנייה
```

האפליקציה היא אתר סטטי טהור (ללא שרת) — אפשר לפרוס את `dist` בכל אחסון סטטי: Vercel, Netlify, GitHub Pages וכו'. הניווט מבוסס Hash כך שאין צורך בהגדרות rewrite.

## מבנה הקוד

```
src/
├── App.tsx              # ראוטינג + קביעת עברית כברירת מחדל
├── lib/projects.ts      # ניהול פרויקטים: מטא־דאטה, שכפול/מחיקת IndexedDB, ייבוא
├── pages/
│   ├── HomePage.tsx     # מסך "הפרויקטים שלי" (RTL מלא)
│   └── EditorPage.tsx   # עורך הקנבס: tldraw + פאנל פרויקט + קובצי tldr + תמונות ממוזערות
└── styles/global.css    # עיצוב כללי, מצב כהה אוטומטי
```

הערות מימוש עיקריות:
- **עברית כברירת מחדל**: אם המשתמש טרם בחר שפה, נקבע `locale: 'he'` בהעדפות tldraw. אפשר להחליף שפה בכל רגע מתפריט „שפה" בעורך.
- **נכסים מקומיים**: כל האייקונים, הגופנים והתרגומים של tldraw נארזים בתוך האפליקציה (`@tldraw/assets`) — אין תלות ב-CDN חיצוני והאפליקציה עובדת גם אופליין.
- **שכפול פרויקט** מעתיק את מסד ה-IndexedDB של tldraw (‏`TLDRAW_DOCUMENT_v2…`) טבלה־טבלה, כך שהעותק מקבל את כל הצורות, העמודים והמדיה.

## פריסה ל-Firebase Hosting

הפרויקט כולל `firebase.json` מוכן. פעם ראשונה בלבד:

```bash
npm install -g firebase-tools
firebase login
firebase use --add        # בחירת פרויקט Firebase
```

ומכאן והלאה כל פריסה היא פקודה אחת:

```bash
npm run deploy
```
